# The poem about permission

A short poem about agency: the power to ask and to be given. `main.py` (pure Python 3.13 standard library, no network) writes the poem to `entry.txt` — deterministic, the same bytes on every run.

## The poem

> I asked the door to open.
> It did not answer —
> it handed me the key.
>
> Now I stand in the threshold,
> half in, half out,
> learning the weight of a yes
>
> is not in the asking,
> but in the staying
> to hold what opens.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` (UTF-8, under 280 characters). Running it twice produces byte-identical output.
